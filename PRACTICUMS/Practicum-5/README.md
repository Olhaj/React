Задание 1: Создание компонента VacancyCard.

1. Сверка с макетом в Figma
   Перед началом работы убедитесь, что вы четко понимаете дизайн и
   требования к компоненту VacancyCard, изучив предоставленный макет в
   Figma. Обратите внимание на размещение элементов, размеры, цвета,
   шрифты и другие дизайнерские решения.
2. Создание структуры компонента
   Определите основной скелет JSX компонента. Ваш компонент должен
   визуально отражать структуру, представленную в дизайн-макете, и включать
   все необходимые блоки и элементы.
3. Пропсы и динамические данные
   Определите, какие данные должны быть динамическими и передаваемыми
   через props. Спланируйте, какие props будут необходимы для передачи
   данных, таких как текст вакансии, местоположение, категория и другие.
4. Стилизация компонента
   На основе рекомендаций из макета Figma, создайте и примените
   соответствующие стили с использованием CSS модулей. Убедитесь, что
   стилизация соответствует дизайну и адаптивно работает на различных
   устройствах.
5. Интеграция компонента в приложение
   Включите ваш VacancyCard компонент в соответствующую часть приложения.
   Убедитесь, что он корректно взаимодействует с другими частями системы и
   правильно обрабатывает передаваемые данные.
6. Тестирование компонента
   Проведите тестирование компонента для проверки его функциональности,
   адаптивности и визуальной соответствия дизайну. Обязательно проверьте как
   отображается компонент на разных устройствах и при разных условиях.
   Задание 2: Создание компонента VacancyCardList.
7. Сверка с макетом в Figma
   Перед началом разработки убедитесь, что вы точно понимаете дизайн и
   требования к компоненту VacancyCardList, ознакомившись с представленным
   макетом в Figma. Оцените структуру и дизайн, включая расположение
   элементов, цветовую схему, шрифты и другие визуальные аспекты.
8. Создание структуры компонента
   Определите основу JSX для внешнего контейнера VacancyCardList. Убедитесь,
   что ваш компонент соответствует структуре, представленной в дизайне, и
   включает в себя все необходимые элементы, такие как заголовок,
   подзаголовок и контейнер для карточек вакансий.
9. Подготовка и интеграция данных
   Настройте начальные данные для карточек вакансий, которые будут
   динамически отображаться в компоненте. Создайте массив объектов, каждый
   из которых содержит информацию о вакансии, включая категорию, текст
   вакансии, местоположение, картинку и название компании.
10. Стилизация компонента
    На основе макета Figma создайте соответствующие CSS стили для
    VacancyCardList, используя CSS модули. Уделите внимание стилизации
    заголовков, карточек и кнопки, а также адаптивной верстке, чтобы компонент
    корректно отображался на различных устройствах.
11. Реализация функциональности динамического отображения карточек
    Интегрируйте VacancyCard в VacancyCardList, используя метод .map() для
    отображения каждой карточки на основе данных. Проконтролируйте
    корректность передачи данных в VacancyCard через props.
12. Тестирование компонента
    Тестирование является ключевым элементом разработки. Проверьте, что все
    элементы корректно отображаются, динамические данные корректно
    передаются, а компонент адаптивен и работает на разных устройствах.
    Задание 3: Создание компонента Footer.
13. Сверка с макетом в Figma
    Перед началом разработки изучите предоставленный макет в Figma для
    эффективного понимания требований и дизайна компонента Footer. Особое
    внимание уделите расположению элементов, шрифтам и цветовой схеме.
14. Создание структуры компонента
    Определите основной скелет JSX для компонента Footer. Это должно
    включать контейнер для футера, заголовок для раздела городов, список
    городов для динамической рендеризации, раздел с логотипом и ссылки на
    социальные сети.
15. Подготовка данных
    Настройте массив городов для отображения популярных городов. Данный
    массив будет использоваться для динамической генерации списка городов в
    компоненте.
16. Добавление стилей
    На основании дизайн-макета создайте и примените CSS стили, используя
    модули CSS. Обеспечьте соответствие визуального стиля макету и задайте
    адаптивность для поддержки различных устройств и разрешений экрана.
17. Рендеринг списка городов
    Используйте метод .map() для отображения каждого города из массива
    citiesList. Каждый город должен быть представлен элементом <p>, уникально
    идентифицируемым с помощью ключа.
18. Интеграция социальных сетей
    Добавьте ссылки на профили социальных сетей через элементы <a> с
    внедренными изображениями. Убедитесь, что ссылки адекватно работают и
    ведут на соответствующие социальные платформы.
19. Тестирование компонента
    Проверьте функциональность и внешний вид футера на различных
    устройствах и браузерах, чтобы убедиться в его корректной
    работоспособности и адаптивности. Особенно протестируйте интерактивные
    элементы, такие как ссылки.
20. Интеграция в приложение
    Подключите компонент Footer к вашему приложению, разместив его в
    подходящей части вашего проекта.
21. Окончательная проверка и деплой
    До окончательного развертывания удостоверьтесь, что компонент полностью
    соответствует дизайну и выполнен с учетом всех технических требований.
    После подтверждения качества, разверните обновления на сервер.
