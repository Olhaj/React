React Урок 5

Как перенести макет из Figma в компоненты React

Задача урока — научиться читать дизайн-макет, подготовить изображения и собрать страницу из отдельных компонентов. Сначала изучаем макет и его параметры, затем создаём структуру проекта и JSX, подключаем CSS Modules и сравниваем результат с оригиналом.

ГЛАВНЫЙ ПОДХОД Не верстай всю страницу одним большим блоком. Раздели макет на смысловые части, создай компоненты и собирай из них страницу.

1. Что такое Figma и что смотреть в макете

Figma — инструмент для создания макетов интерфейсов и интерактивных прототипов. В команде несколько человек могут смотреть и обсуждать один дизайн. Для разработчика макет служит источником размеров, отступов, цветов, шрифтов, изображений и расположения элементов.

Открой нужную страницу или frame макета и найди нужный экран.

Выбирай элементы, чтобы посмотреть ширину, высоту, шрифт, цвет и другие параметры.

С зажатым Alt (Option на Mac) смотри расстояние между элементами.

В правой панели проверь цвет, типографику и параметры экспорта.

Экспортируй нужные изображения и иконки, например в SVG или PNG, и положи их в assets.

ПОЛЕЗНО Перед началом составь короткий список блоков страницы и важных параметров дизайна. Так меньше шансов забыть элемент или наугад задать отступы.

2. Подготовка структуры проекта

Разделяй переиспользуемые части интерфейса, страницы и ресурсы. В уроке для оформления выбраны CSS Modules: имена классов локальны для компонента и реже конфликтуют.

src/
assets/ изображения и иконки
components/ Header, SearchBar, CategoryCard...
pages/ страницы, собранные из компонентов
App.jsx

Варианты стилей: обычный CSS подходит для простых проектов; SCSS добавляет переменные и вложенность; Styled Components задаёт стили через JavaScript; CSS Modules изолируют классы. Важно придерживаться одного понятного подхода в проекте.

3. Собираем страницу по частям

Header — верхняя часть

Обычно содержит логотип, навигацию и кнопки входа или регистрации. Сначала определи элементы по макету, затем создай JSX и стили, после чего сравни с Figma.

import styles from './Header.module.css';

function Header() {
return (
<header className={styles.header}>
<img src="/assets/logo.svg" alt="Логотип" />
<nav>Каталог　 О нас</nav>
<button>Войти</button>
</header>
);
}
export default Header;

Main — основное содержимое

Main располагается между шапкой и подвалом. Он объединяет крупные блоки, например SearchBar, CategoryCardList и список вакансий. Подкомпоненты импортируются и располагаются в нужном порядке.

function Main() {
return (
<main>
<SearchBar />
<CategoryCardList />
<VacancyCardList />
</main>
);
}

SearchBar — поиск

В макете урока блок поиска включает заголовок, форму с двумя полями (должность или компания и местоположение), кнопку и блок логотипов компаний. Разделяй форму и логотипы на вложенные контейнеры, чтобы проще было стилизовать.

function SearchBar() {
return (
<section>
<h1>Найди подходящую работу</h1>
<form>
<input placeholder="Должность или компания" />
<input placeholder="Город или страна" />
<button type="submit">Найти</button>
</form>
<div className={styles.companies_logos}>
{/_ логотипы компаний _/}
</div>
</section>
);
}

CategoryCard — одна карточка

Карточка получает объект cardInfo через props. В нём есть url картинки и text — название категории. Изображению укажи alt, а оформление возьми из CSS Module.

import styles from './CategoryCard.module.css';

function CategoryCard({ cardInfo }) {
return (
<article className={styles.category_card}>
<img src={cardInfo.url} alt={cardInfo.text} />
<p>{cardInfo.text}</p>
</article>
);
}

CategoryCardList — список карточек

Храни категории в массиве данных и создай карточку для каждого объекта через .map(). Последняя дополнительная карточка может вести на раздел «Больше категорий».

function CategoryCardList() {
const categories = [
{ id: 1, text: 'Дизайн', url: '/assets/design.svg' },
{ id: 2, text: 'Разработка', url: '/assets/code.svg' },
];
return (
<section>
<h2>Категории</h2>
<div className={styles.category_list}>
{categories.map(item => <CategoryCard key={item.id} cardInfo={item} />)}
<button>Больше категорий</button>
</div>
</section>
);
}

4. Как работать с CSS Modules

Создай файл с окончанием .module.css, импортируй его как объект styles и используй имя класса через точку. В CSS имя может быть, например, category_card; в JSX оно вызывается как styles.category_card.

/_ CategoryCard.module.css _/
.category_card {
border-radius: 12px;
padding: 16px;
background-color: white;
}

/_ JSX _/

<article className={styles.category_card}>...</article>

ВАЖНО В уроке предлагается называть CSS-классы в snake_case: category_card. Главное — одинаково писать имя в CSS-файле и при обращении через styles.

5. Проверка соответствия макету

Запусти приложение и сравни его с Figma при одинаковом масштабе.

Проверь размеры, расстояния, выравнивание, цвета и шрифты.

Убедись, что все изображения загрузились и имеют подходящий размер.

Проверь поведение страницы на разных ширинах экрана.

Если блок выглядит не так, поправь структуру JSX или CSS и сравни снова.

ИТОГ Figma помогает понять, что и как нужно сверстать. React-компоненты делят интерфейс на части, props передают карточкам данные, CSS Modules задают локальные стили, а проверка в браузере помогает приблизить результат к макету.
