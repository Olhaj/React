Export и Import

1. Создайте новый проект React.
2. Подготовьте проект к работе, как вы делали это на предыдущих уроках.
3. Помимо папки components в src создайте папку utils.
4. В этой папке создайте .js файл, назовите его “UsefulFunction”.
5. В файле напишите две функции, первая должна перемножать первое число на второе, вторая делить.
   Экспортируйте функции, используя именной экспорт.
6. В папке components создайте компонент ( .jsx файл ) , в который мы будем импортировать функции,
   назовите его “ShowCalc”
7. Напишите стандартную структуру компонента в файле, импортируйте в него функции.
8. Сделайте так, чтобы компонент отображал результаты вычислений, производимых функциями.
9. Экспортируйте получившийся компонент и импортируйте его в файл App.js, сделайте так, чтобы он
   отображался на экране.
10. Запустите приложение, проверьте результат.

DefaultProps
Вы разрабатываете Todo-приложение и хотите создать компонент TodoItem, который будет использоваться
для отображения одного элемента списка дел.

1. Создайте компонент “TodoItem”, он должен принимать следующие props:
   ○ text - текст элемента в списке (строка)
   ○ isCompleted - флаг, показывающий, выполнено ли дело (boolean)
2. Добавьте defaultProps к компоненту TodoItem, которые устанавливают значения по умолчанию для
   следующих ситуаций:
   ○ Если text не предоставлен, должен использоваться текст: “Новая задача”.
   ○ Если isCompleted не передан, его то значение должно быть false, а рядом с текстом задачи
   должен быть текст “Не решена”.
3. Отобразите компонент в приложении.
4. Запустите приложение, проверьте результат.

Prop key и .map()

1. Создайте компонент MusicAlbum, который выводит информацию о музыкальном альбоме на основе
   переданных ему данных. Данные должны включать в себя имя артиста, название альбома и список
   песен.
2. Создайте компонент AlbumList, который использует MusicAlbum для отображения списка альбомов.
3. Компонент MusicAlbum должен:
   ○ Принимать props: artist, title, и tracks.
   ○ Отображать имя артиста и название альбома.
   ○ Выводить список песен в виде ненумерованного списка (<ul>).
4. Компонент AlbumList должен:
   ○ Использовать метод .map() для создания массива компонентов MusicAlbum, передавая
   соответствующие props и уникальный ключ key.
   ○ Отображать каждый MusicAlbum в списке.
