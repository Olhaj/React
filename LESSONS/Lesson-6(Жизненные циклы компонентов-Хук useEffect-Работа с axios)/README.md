React Урок 6

Жизненный цикл, useEffect и запросы Axios

В уроке разбираются три связанные темы: что происходит с компонентом во время его жизни, как выполнять побочные эффекты через useEffect и как получать или менять данные на сервере через Axios.

ГЛАВНОЕ useEffect связывает компонент с внешними действиями. Axios отправляет HTTP-запросы. Для надёжной загрузки данных обработай состояние загрузки и ошибки, а ненужные эффекты очищай.

1. Жизненный цикл компонента

Компонент проходит этапы: монтирование (появляется на странице), обновление (изменились props или state) и размонтирование (удаляется). В классовых компонентах с ними связаны componentDidMount, componentDidUpdate и componentWillUnmount. В функциональных компонентах похожие задачи обычно решают хуками, прежде всего useEffect.

ПОМНИ Методы жизненного цикла классов полезно узнавать в старом коде. В новых примерах этого урока используем функциональные компоненты и useEffect.

2. Что делает useEffect

Побочный эффект — действие вне простого расчёта JSX: запрос к API, подписка на событие, таймер или синхронизация с заголовком вкладки. useEffect принимает функцию эффекта и, при необходимости, массив зависимостей.

useEffect(() => {
document.title = title;
}, [title]);

Как читать зависимости:

Без второго аргумента — эффект запускается после каждого рендера.

Пустой массив [] — эффект запускается после первого отображения; очистка выполняется при удалении компонента.

Массив [value] — эффект повторяется после отображения, когда value изменился. Перед повторным запуском React сначала выполнит очистку предыдущего эффекта.

ВАЖНО Указывай в массиве зависимости все значения props и state, которые эффект использует. Иначе эффект может работать с устаревшими данными.

3. Очистка эффекта

Эффект может вернуть функцию очистки. Её используют, чтобы удалить слушатель, остановить таймер, закрыть соединение или отменить ненужный запрос. React вызывает очистку перед следующим запуском эффекта и при размонтировании компонента.

useEffect(() => {
const timerId = setInterval(() => {
setSeconds(value => value + 1);
}, 1000);

return () => clearInterval(timerId);
}, []);

4. Axios и HTTP-запросы

Axios — библиотека для HTTP-запросов. Она возвращает Promise и удобно работает с JSON. Установка в проекте: npm install axios. Ответ обычно содержит response.data (данные) и response.status (HTTP-статус). Ошибки запроса обрабатывай явно.

Основные методы

GET — получить данные: axios.get(url).

POST — создать или отправить данные: axios.post(url, data).

PUT — заменить ресурс целиком: axios.put(url, data).

PATCH — частично обновить ресурс: axios.patch(url, changes).

DELETE — удалить ресурс: axios.delete(url).

РАЗНИЦА PUT И PATCH PUT обычно отправляет полную новую версию ресурса; PATCH передаёт только изменяемые поля. Точное поведение зависит от API.

5. Загрузка данных при открытии компонента

Для запроса при первом отображении используют useEffect с пустым массивом зависимостей. Данные сохраняют в state, чтобы показать их в JSX. Также полезно показывать загрузку и ошибку.

import { useEffect, useState } from 'react';
import axios from 'axios';

function Posts() {
const [posts, setPosts] = useState([]);
const [loading, setLoading] = useState(true);
const [error, setError] = useState('');

useEffect(() => {
async function loadPosts() {
try {
const response = await axios.get('https://jsonplaceholder.typicode.com/posts');
setPosts(response.data);
} catch (err) {
setError('Не удалось загрузить записи');
} finally {
setLoading(false);
}
}
loadPosts();
}, []);

if (loading) return <p>Загрузка...</p>;
if (error) return <p>{error}</p>;
return <ul>{posts.map(post => <li key={post.id}>{post.title}</li>)}</ul>;
}

ASYNC / AWAIT Ключевое слово await используют внутри async-функции. try/catch обрабатывает успех и ошибку, finally выполняется в обоих случаях. Не объявляй сам callback useEffect как async; создай async-функцию внутри эффекта и вызови её.

6. Отправка данных

Запросы, которые меняют сервер, обычно отправляют в ответ на действие пользователя — например, клик по кнопке или отправку формы, а не автоматически при каждом рендере.

async function createPost() {
const post = { title: 'Новая запись', body: 'Текст', userId: 1 };
try {
const response = await axios.post(
'https://jsonplaceholder.typicode.com/posts',
post
);
console.log('Создана запись:', response.data.id);
} catch (error) {
console.error('Не удалось создать запись', error);
}
}

<button onClick={createPost}>Создать запись</button>

7. Дополнительные возможности Axios

Для повторяющихся настроек можно создать экземпляр Axios с общим baseURL и заголовками. Интерсепторы могут добавлять токен или вести лог до отправки запроса и после получения ответа. Таймаут ограничивает время ожидания; запрос можно отменить, если он стал не нужен, например при смене страницы.

const api = axios.create({
baseURL: 'https://api.example.com',
timeout: 5000,
});

// затем: api.get('/posts')

Короткая памятка

useEffect(fn) — после каждого рендера; useEffect(fn, []) — после первого отображения; useEffect(fn, [x]) — при изменении x.

Функция return из эффекта очищает подписки и таймеры.

Axios: GET читает, POST создаёт, PUT заменяет, PATCH меняет часть, DELETE удаляет.

Для запроса: loading → данные или error → завершение.

Асинхронные операции обрабатывай через await и try/catch/finally.

ИТОГ useEffect запускает синхронизацию с внешним миром по нужным зависимостям. Axios общается с API. Вместе они позволяют загрузить данные, показать их в React и корректно обработать загрузку, ошибки и очистку.
