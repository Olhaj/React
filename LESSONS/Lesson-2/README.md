React Урок 2

Компоненты, JSX и props — короткий конспект без потери главного

Урок учит собирать интерфейс из компонентов, передавать им данные через props и выводить повторяющиеся элементы из массивов. Это основа для создания понятных и переиспользуемых React-приложений.

ОСНОВНАЯ ИДЕЯ Компонент получает входные данные (props) и возвращает JSX. Родитель передаёт данные детям сверху вниз; дочерний компонент отображает их, но сам props не меняет.

1. Компоненты

Компонент — самостоятельная часть интерфейса, обычно функция в отдельном файле. Компоненты можно повторно использовать и вкладывать: например, App содержит Header, Main и Footer, а Header — заголовок и логотип.

function Greeting() {
return <h1>Привет!</h1>;
}
export default Greeting;

Функциональные компоненты — современный стандарт. Классовые компоненты встречаются в старом коде, но для новых примеров обычно достаточно функций и хуков.

ПРАВИЛО Имя компонента начинается с большой буквы: Greeting. HTML-теги пишутся с маленькой: h1, div.

2. Импорт и экспорт

Модуль — отдельный файл с кодом. Экспорт делает функцию доступной другим файлам, импорт подключает её там, где она нужна.

// Greeting.jsx
export default function Greeting() {
return <h1>Привет!</h1>;
}

// App.jsx
import Greeting from './Greeting.jsx';

function App() {
return <Greeting />;
}
export default App;

Именованный экспорт удобен, когда из одного файла нужно отдать несколько функций. При импорте их имена берутся в фигурные скобки.

// math.js
export function multiply(a, b) { return a \* b; }
export function divide(a, b) { return a / b; }

// useMath.js
import { multiply, divide } from './math.js';

3. JSX

JSX — синтаксис разметки, похожий на HTML, который пишут внутри JavaScript-компонента. Сборщик проекта преобразует JSX в JavaScript, понятный React.

const name = 'Аня';
const fruits = ['Яблоко', 'Груша'];

function Example() {
return (
<div>
<h1>Привет, {name}!</h1>
<ul>{fruits.map((fruit) => <li key={fruit}>{fruit}</li>)}</ul>
<button onClick={() => alert('Нажато')}>Нажми</button>
</div>
);
}

В фигурные скобки помещают JavaScript-выражения: переменные, вычисления, вызовы функций и .map(). Обработчик события передают как функцию, например onClick={handleClick}.

JSX-ПАМЯТКА Верни один корневой элемент (или фрагмент <>...</>); закрывай каждый тег; class в JSX пишется className; одиночные теги заканчиваются /> — например <img />.

Файлы могут иметь расширение .js или .jsx: оба варианта зависят от настроек проекта. Следуй принятому в проекте стилю.

4. Props — данные для компонента

Props (properties) — свойства, которые родитель передаёт дочернему компоненту. Это похоже на аргументы функции. Через props можно передавать строки, числа, boolean, массивы, объекты и функции.

function Title(props) {
return <h1>{props.text}</h1>;
}

function App() {
return <Title text="Мой сайт" />;
}

Чтобы не писать props.text много раз, объект можно деструктурировать прямо в параметрах функции.

function Title({ text, color = "navy" }) {
return <h1 style={{ color }}>{text}</h1>;
}

ЗАПОМНИ Props доступны только для чтения. Данные идут в одном направлении: от родителя к ребёнку. Если ребёнку нужно сообщить родителю о действии, родитель может передать функцию-обработчик через props.

5. Значения по умолчанию

Значение по умолчанию используется, если родитель не передал нужный prop. Для функциональных компонентов удобно задавать его при деструктуризации:

function TodoItem({ text = "Новая задача", isCompleted = false }) {
return (
<p>{isCompleted ? "Решена" : "Не решена"}: {text}</p>
);
}

В учебных материалах также встречается defaultProps. Для простых функциональных компонентов в этом конспекте используем значения по умолчанию в параметрах.

6. Props.children

Когда содержимое помещено между открывающим и закрывающим тегами пользовательского компонента, оно приходит в него как children. Это удобно для обёрток и повторно используемых блоков.

function Box({ children }) {
return <div className="Box">{children}</div>;
}

function App() {
return <Box><p>Текст внутри блока</p></Box>;
}

7. Списки, .map() и key

Для каждого элемента массива часто создают JSX-элемент через .map(). Каждому элементу списка нужно назначить уникальный и стабильный key, чтобы React мог сопоставлять элементы при обновлении.

const todos = [
{ id: 1, text: "Выучить JSX" },
{ id: 2, text: "Сделать практику" },
];

function TodoList() {
return (
<ul>
{todos.map((todo) => (
<li key={todo.id}>{todo.text}</li>
))}
</ul>
);
}

ВАЖНО ПРО key Предпочитай уникальный id из данных. Индекс массива подходит только для списка, который не меняет порядок и состав; иначе React может неверно сопоставить элементы.

8. Проверка типов props

prop-types помогает в режиме разработки заметить, если компоненту передали значение не того типа. Это предупреждение, а не замена проверке данных во время выполнения.

import PropTypes from 'prop-types';

function Card({ title, inStock, price }) {
return (
<article>
<h2>{title}</h2>
<p>{inStock ? 'В наличии' : 'Нет в наличии'}</p>
<p>{price} €</p>
</article>
);
}

Card.propTypes = {
title: PropTypes.string.isRequired,
inStock: PropTypes.bool,
price: PropTypes.number,
};

ИСПРАВЛЕНИЕ ОПЕЧАТКИ ИЗ PDF Свойство называется propTypes (с заглавной T), а не prototype. Для обязательного свойства добавляют .isRequired. В современных проектах проверку типов также часто описывают через TypeScript.

9. Что нужно уметь после урока

Создать функциональный компонент, экспортировать его и импортировать в другой файл.

Написать JSX с переменными в фигурных скобках и корректно закрывать теги.

Передать props от родителя ребёнку, получить их и задать значения по умолчанию.

Использовать children, если содержимое передают между тегами компонента.

Вывести массив через .map() и назначить элементам стабильный key.

Описать ожидаемые типы props через propTypes, если проект это использует.

САМОЕ КОРОТКОЕ Компоненты строят интерфейс. JSX описывает его структуру. Props передают данные вниз. Children передаёт вложенное содержимое. .map() создаёт элементы списка, а key помогает React их отслеживать.
